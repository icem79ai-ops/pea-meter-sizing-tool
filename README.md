# PEA Meter Sizing Tool

Web app คำนวณขนาดมิเตอร์ไฟฟ้า (โหลด ≤ 80% ของพิกัด) สำหรับงานระบบจำหน่ายไฟฟ้า

## ใช้งานออนไลน์
https://icem79ai-ops.github.io/pea-meter-sizing-tool/

ใช้งานได้บนเครื่องใดก็ได้ — ข้อมูลเก็บใน browser (localStorage) ไม่ต้องมีเซิร์ฟเวอร์ ทำได้ offline

## ฟีเจอร์
- เพิ่มเครื่องใช้ไฟฟ้าจากปุ่มสำเร็จรูป (แอร์/หลอด LED/ปั๊ม/เครื่องทำน้ำอุ่น/EV/ลิฟต์) หรือเครื่องเอง
- ปรับ BTU แอร์ → กำลังไฟฟ้าคำนวณให้อัตโนมัติ
- ปรับ PF / ดีมานด์แฟกเตอร์ ได้ในตาราง แก้สิทธิ์แล้วผลลัพธ์อัปเดตทันที
- ลบรายการที่เพิ่มผิดด้วยปุ่ม ✕ ในตาราง
- หลายโปรเจกต์ + backup/restore ข้อมูล
- Export CSV และ Excel 3 ชีต (สรุป / รายการเครื่องใช้ / ตารางโหลด) พร้อมฟอร์แมต

## ใช้งานท้องถิ่น
เปิด `index.html` ใน browser ได้เลย หรือใช้ live server:
```
python -m http.server 8000
```
แล้วเปิด http://localhost:8000

## สร้าง/ทดสอบ app.js
โค้ดแยกเป็น `parts/p1.js`–`p7.js` รวมเป็น `app.js` เพื่อให้แก้ทีละไฟล์ง่าย
```
Get-Content parts\p*.js -Raw | Out-File app.js -Encoding utf8
```

## การคำนวณ
- กำลังติดตั้ง (kVA) = W × จำนวน / 1000 / PF
- ดีมานด์ (kVA) = ติดตั้ง × DF%
- กระแส 1 เฟส = kVA × 1000 / (V × PF)
- กระแส 3 เฟส = kVA × 1000 / (√3 × V × PF)
- เลือกมิเตอร์ที่โหลด ≤ 80% ของพิกัด
